02

PAIN POINTS

传统手段，发现火情总是慢一步

🔥 隐患密集

高校 / 科研实验室易燃易爆试剂、电气设备密集，明火、电火花隐患高发。

⏱️ 感知滞后

烟感 / 温感需烟雾、热量扩散到探头才触发，明火初期的关键几十秒被错过。

👁️ 盯防漏检

人工 24h 盯监控不现实，多路视频靠人眼巡检，疲劳漏检率高。

📹 资源闲置

已部署的大量摄像头仅用于事后取证，未参与"事前"主动预警。

🧯 误报困扰

传统算法对反光、汽雾、焊接等场景误报多，逐渐被值守人员忽视。

📈 责任重大

一旦成灾，人员与贵重仪器损失巨大，安全责任与社会影响极高。

政策驱动

教育部 / 应急管理强化实验室安全主体责任，要求隐患"早发现、早预警、早处置"。

技术成熟

让"只能事后回放"的摄像头，升级为"能看懂火情、会主动报警"的安全哨兵。

06

INNOVATION

核心创新点

① 多模态大模型替代单点传感

用"看懂画面语义"取代烟感/温感的物理触发，初期明火即可识别，不必等烟热扩散。

② 火情专项微调

面向火、火花、电气电弧、烟雾、异常强光构建数据集与微调，区分真火与反光/汽雾/焊接等干扰。

③ 零硬件改造复用

直接接入既有摄像头与网络，软件即开即用，部署成本与周期大幅降低。

④ 时序多帧确认

结合连续帧与运动信息做置信度融合，在保证灵敏度的同时把误报压到可用水平。

VALUE

应用价值

  • 安全价值：把火情发现窗口从"冒烟后"提前到"起火初期"，争取黄金处置时间，护人护设备。
  • 经济价值：复用既有摄像头，建设成本低；避免一次重大火灾即可覆盖系统投入。
  • 社会价值：响应实验室安全治理，形成可复制的智慧安全样板。
  • 推广价值：架构可平移至工厂、仓储、机房、文博等多类视频安防场景。
